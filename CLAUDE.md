# CLAUDE.md — The Log

Persistent project memory for Claude Code sessions

## What This Project Is

The Log is a voice-first AI coaching PWA. It interviews users once on onboarding, prescribes daily workouts each morning, collects voice logs each evening, and surfaces weekly patterns and programs. The core quality bar: every AI output must feel written by a coach who knows this specific person — not generated generically.

## Current Phase

Phase 1 — Personal proof of concept. Single authenticated user. No paywall. No app store. The founder (James) is the only user. Goal: validate that the daily loops work and the AI outputs are genuinely specific before opening to others.

## Stack

- React + Vite (frontend)
- Tailwind CSS (styling)
- Supabase (database, auth, storage)
- OpenAI Whisper API — voice transcription
- Anthropic Claude API (claude-sonnet-4-20250514) — AI brain
- Vercel (hosting)
- vite-plugin-pwa (PWA)

## Environment Variables

```
VITE_SUPABASE_URL        (frontend)
VITE_SUPABASE_ANON_KEY   (frontend)
ANTHROPIC_API_KEY        (server-side only — Vercel env, no VITE_ prefix)
OPENAI_API_KEY           (server-side only — Vercel env, no VITE_ prefix)
```

Supabase vars use `import.meta.env.VITE_*`. Claude and Whisper keys live only in Vercel environment variables and are accessed via `process.env` in `/api/*` routes — never exposed to the browser.

## Database Tables

- **user_profiles** — onboarding profile, one row per user
- **daily_logs** — morning and evening logs, one row per log per day
- **workouts** — prescribed daily workouts, generated by Claude
- **weekly_programs** — 7-day programs + weekly recaps, generated Sundays

Full schema in PRD. Key flag: `user_profiles.onboarding_done` — if false, always redirect to `/onboarding`.

## Prompt Rules

All Claude prompts live in `/src/lib/prompts.js` as builder functions. Never write a prompt string inline in a component or page. Every prompt must inject user-specific context — profile, last log, recent patterns. If the context is empty or unavailable, surface an error — do not fall back to generic output.

### Forbidden phrases in any Claude output

- "Great work"
- "You've got this"
- "Stay consistent"
- "Keep it up"
- Any generic encouragement not tied to specific logged data

## Voice Recording

Uses MediaRecorder API with auto-detected MIME type (webm/mp4/aac/ogg — supports Safari/iOS). The `useVoiceRecorder` hook handles all recording state. `VoiceRecorder.jsx` is the only component that renders recording UI — never duplicate this. Max recording length: 3 minutes (auto-stop). After stop: blob goes to Whisper with correct file extension → transcript returned as string.

## Routing

```
/              Home (dashboard)
/onboarding    First-time voice interview
/morning       Morning prompt + workout
/evening       Evening log sequence
/weekly        Weekly program + recap
```

Auth guard on all routes except `/onboarding`. If `onboarding_done = false`, redirect from `/` to `/onboarding`.

## Design Rules

- Background: `#0D0D0D` everywhere
- Surface cards: `#1A1A1A`
- Text: `#F0F0F0`
- Muted: `#888888`
- Record button active: `#FF3B30`
- Font: Inter, weights 400 and 600 only
- Mobile-first: test at 390px width
- One primary action per screen
- No typing anywhere in core loops — voice only

## What NOT To Do

- Do not add features not in the PRD without asking
- Do not write prompts inline — always use `prompts.js`
- Do not add a free tier, paywall, or subscription logic in Phase 1
- Do not allow onboarding to be skipped
- Do not use localStorage for anything sensitive — use Supabase
- Do not add TypeScript unless explicitly asked — stay in JSX
- Do not over-engineer — default to the simplest implementation that works
